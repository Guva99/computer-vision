# Калибровки, при которых сняты golden-файлы

Здесь лежат `extrinsic.json` и `table_plane.json` в том виде, в каком они были
на коммите `26d32ac` (2026-10-27) — тогда и записывались golden.

**Зачем копия.** 2026-11-03 камеру сдвинули вправо, чтобы в кадр влез магазин,
и обе калибровки переписали (коммит `4539514`). Детекция считает высотный гейт
по плоскости стола и строит FK-самофильтр по внешней матрице, поэтому после той
правки регрессия показывала расхождение на всех восьми записях — и отличить
настоящую поломку от смены калибровки стало нельзя. Оракул молча умер и
пролежал мёртвым шесть дней.

**Доказано 2026-11-09:** с этими файлами регрессия даёт 0 отличий из 2 на
быстром наборе. То есть конвейер бит-в-бит прежний, а расходились только
калибровки.

Поэтому `tools/regress.py` подставляет их сам. Переснимать golden при каждом
сдвиге камеры не нужно: запись и калибровка — одна пара, и хранить их надо
вместе.

**Правило:** меняешь golden — клади сюда калибровки того же прогона.
